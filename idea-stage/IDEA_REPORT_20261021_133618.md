# 3DGS 形状与增密：具体创新候选
日期：2026-10-21。范围：静态多视图重建，已有官方 3DGS truck 复现，RTX 5070 约 12 GB。仅方案与文献核查；本轮未修改研究代码、未运行 GPU 实验。

## 当前建议
优先做“分裂后兄弟高斯的共同运动与相对分离解耦优化”；备选做“按分裂净增渲染工作量分配增密预算”。这里给出可执行的候选差异，不宣称已经证明首次提出或有效。

## 候选 1：分裂后兄弟高斯的共同运动与相对分离解耦优化
### 具体做法
1. 保持既有二分裂候选、方向、位置、数量、尺度和不透明度初始化一致。
2. 在出生后的短窗口，把两个位置写成 x1=c+d、x2=c-d。分别对共同中心 c 和相对位移 d 运行 Adam；梯度为 gc=g1+g2、gd=g1-g2。
3. 经过预定次数的可见更新后，恢复普通位置优化。所有组保持一致的状态重置规则；首版不引入状态继承，也不修改渲染器。
4. 为排除坐标缩放造成的假收益，加入正交归一化版本，或补偿梯度/学习率尺度，并比较充分调参的独立 Adam。

### 待验证假设
兄弟高斯的共同移动与细节分离可能有不同的优化统计；对角 Adam 的坐标依赖使两者分开优化可能更有效。仅重新写坐标不是贡献；贡献必须是可重复机制与效果。

### 最小实验与停止条件
先在 CPU 用两个二维高斯拟合两个窄峰，比较独立 Adam、c/d Adam、调过学习率的独立 Adam 和 SGD。再从同一增密前完整 checkpoint 顺序继续 500–1000 步，固定随机分裂、相机次序和高斯数，并先暂停后续增密。比较验证误差、兄弟梯度相关性、共同/分离位移与实际耗时。
若收益能由简单学习率调整或切换状态重置解释，或玩具实验优势不能转移到 truck，就不继续将其作为主方向。后续再测多个场景和相同时间预算。
实现工期估计：2–4 个工作日做玩具诊断和位置原型；真实接入与多场景验证另计。估计短分支试验总额控制在 2 GPU 小时内，实际时间须先用当前机器短测校准，本轮消耗 0 GPU 小时。

### 最近工作与差异
- [SteepGS](https://arxiv.org/abs/2505.05587)：分裂必要性、方向和后代数量；需核查其推导是否已包含分裂后的共同/相对优化。
- [Improving Densification](https://arxiv.org/abs/2508.12313)：长轴分裂、多步更新和恢复管理；本候选固定分裂初始化，只改变短期优化坐标。
- [Learn2Splat](https://arxiv.org/abs/2605.15760)：利用高斯间依赖的学习型优化器。本候选是已有兄弟关系上的解析坐标变换，仍需直接比较其相关分析。
- [BOGausS](https://arxiv.org/html/2504.01844v1)：子高斯状态继承已做过，必须保持状态处理一致，不能以“继承历史”作为本候选创新。

## 候选 2：按分裂净增渲染工作量分配增密预算
### 具体做法
1. 保留原来的候选评分与分裂操作。
2. 在少量固定训练视角上，估计每个候选父高斯及拟议子高斯与图像 tile 的相交次数。
3. 计算净成本 ΔC=C(children)-C(parent)，用其分配本轮增密预算。净成本可为负，不能简单禁止大高斯分裂。
4. 比较真实渲染毫秒数与质量，并计入成本估计的训练开销。tile 相交次数只是代理量，不等于实际运行时间。
### 最小实验
先用现有训练检查点/模型与固定视角，判断 tile 工作量是否比高斯数更能解释实测时间。若没有额外解释能力，停止这个代理量。随后比较原版、点数预算、半径约束、净工作量预算。分别报告相近点数与相近实测帧时的质量。
首版估计 2–4 个工作日，尽量用已有投影统计与 Python 实现，不先改 CUDA；候选对子投影或统计不可得时需另估实现量。先做单场景短试验，GPU 预算上限 2 小时，实际耗时未经校准。
### 最近工作与差异
- [Taming 3DGS](https://humansensinglab.github.io/taming-3dgs/)：固定高斯数量预算。
- [SAD-GS](https://vcai.mpi-inf.mpg.de/projects/SAD-GS/)：投影范围与纹理频率决定各向异性分裂。
- [ByteSplat](https://arxiv.org/html/2610.02851v1) §5：已有硬件压力与 tile 负载驱动剪枝，不能声称首次考虑 tile 成本。本候选差异是增密时对拟议子高斯的净增成本决策，不是收敛后的剪枝。
- [Faster-GS](https://fhahlbohm.github.io/faster-gaussian-splatting/assets/hahlbohm2026fastergs.pdf)：优化实现和公平效率基线；必须区分纯工程收益。

## 储备：形状变化感知的父子优化状态迁移
先定义需要保持的子高斯参数更新量，再设计与新形状相匹配的优化历史迁移。梯度矩不能直接当作位移乘 Jacobian；分裂升维也没有唯一迁移。与归零、原样继承、BOGausS 的衰减继承比较，不能宣称精确保持。技术要求更高，暂不作为新手第一实验。
