## 唯一当前路线：固定父集合的分裂时序

方法若最终值得验证，就是：固定同一批待分裂父高斯及同一种 LAS 出生规则；把共享图像射线支持较强的父项安排到不同出生组，在组间正常优化；与组数、出生时间、父项及计算预算相同的随机分组比较。

但我们还没有证明它需要被做。先检查一个更窄的问题：现存真实出生事件中，是否存在材料性的渲染交互、它是否朝坏方向改变 GT MSE、共射线支持图是否比随机分组提供额外定位信息。

不能仅比较“联合损失减单项损失”：即便渲染可加，平方损失本身也有交叉项。固定方案分别保存 R_AB、R_A、R_B、R_0，计算渲染残差 K 和相对可加图像反事实的 GT MSE 差 H。所有正负值原样保留，未裁剪 native RGB 用于区分最终 clamp。

执行方案已在任何新模型计算前写入 [ROOT_PROTOCOL.md](../research/experiments/co-ray-split-interaction-v0/ROOT_PROTOCOL.md)：固定 1481 父项、8 建图训练视角、另 8 效果训练视角、两套随机种子、四组容量；材料性为至少 1% 渲染交互能量、正向 H 达完整当前出生损失的 10%、共射线代理相对两个随机控制至少减少 20%。这只是是否值得再花训练成本的资源门槛，绝非方法通过或统计显著性。

代码与独立 CPU 审计正在准备，尚未读取模型张量、执行投影或渲染。准备完成后先完整阅读代码、冻结哈希，再启动；数值/布局/孩子见证不通过即 NULL，不放宽救结果。整个冻结阶段外部壁钟累计上限 600 秒，0 backward、0 update，不重建优化器。

## 数据边界与文献边界

此次可以用已有 early3600_seed0 出生前 capture，而不是新造训练轨迹。同教师 run 的 7k/30k 只有 PLY。另一个独立 7k checkpoint 可恢复高斯与 Adam，但缺完整历史 RNG/相机栈；不能混作教师同 run 的恢复。input.ply 是 136,029 点的 COLMAP 初始云，不能当作事件模型。历史孩子见证仅有 ID/xyz/activated scale，需补核六字段配方。

[SplatQ](https://arxiv.org/html/2610.13503v1) 已有联合响应交互和删除决策；[COLORING](https://www.ambujtewari.com/research/scherrer12scaling.pdf) 已有冲突支持图调度。我们剩余的窄差异是固定父集合的有限出生事件时序，效果未知。独立查新与 full50 jury 均是同模型家族的 provisional 判断，没有升级成创新接受。

原有 composition 已表明，瞬时损伤更大的分裂也可能有更高的后续收益。因此冻结检查即使通过，也只能支持申请真实短程干预，不能宣称去伪影、加速训练或提高最终质量。
