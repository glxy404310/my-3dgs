# 3DGS形状与增密：20篇文献对照与选题验证

日期：2026-10-21。对象：上一轮两个候选——兄弟高斯共同/相对运动优化，以及按分裂净增渲染工作量分配预算。本轮重点验证后者的研究逻辑，前者另作定向核查。依据现有项目记录假定单张RTX5070约12GB，已复现官方truck；不将论文作者的大显存设备速度当作本机速度。

## 结论先行

宽泛的“形状感知增密”“按重要性减少高斯”“加入预算”都不足以构成可核查的独立贡献。较值得首先诊断的具体问题是：**在分裂前，利用拟议子高斯相对父高斯的净渲染成本，能否比点数预算更好地分配增密机会？**

建议工作题目：**多视角边际渲染成本约束下的高斯增密**。当前结论仅为“有条件进入小规模验证”，不是确认首次提出，也不是保证可发表。此前把兄弟共同/相对优化排为首选的证据不足；它目前更适合作为低成本诊断储备。预算候选的文献动机更明确，但实现和测量要求更高。

## 本次如何落实四步阅读法

1. 核心集合20篇，先读标题、摘要、主要方法图图注、结果表、结论及局限，再对最相近工作回到方法/补充材料。不是20篇逐句精读，也没有逐张视觉检查所有图像。
2. 下文每篇固定记录问题、方法、证据、局限，并把“作者承认”与“本次推断”分开。
3. 横向比较优化对象、预算单位、决策发生阶段和证据边界，不跨论文直接排列PSNR/FPS。
4. 生成五个候选，按本机条件、最小诊断和失败条件筛选。

实读范围：各篇条目给出章节和表图定位；Improving Densification PDF第13–14页Table6及Figure15另已渲染并视觉核对，其余主要依据HTML正文、表格和图注。作者/日期以arXiv元数据补核；正式会议站点用于补核部分发表信息。查询覆盖2024–2026及近六个月，包含10月新稿。Undermind鉴权重试仍不可用，未作为证据；使用官方论文全文、作者项目页及arXiv。

检索词族包括：Gaussian densification rendering latency budget / marginal split cost / children parent tile intersections；shape-aware split overlap / long-axis split rendering cost；Gaussian budget density control / hardware-aware pruning / per-tile memory；Gaussian sibling optimizer / correlated updates / split state inheritance。本文是定向调研，不能据“未检到”推导全世界无人做过。

版本去重：Efficient Density Control (2411.10133)页面声明被Improving Densification替代，合并到P06，不计两篇。KoalaGS及Counting Contributions的会议状态目前保留作者自报标签；Budgeted-GS为投稿稿，ByteSplat为预印本。

## 单篇逻辑卡片

### P01 3D Gaussian Splatting

状态：2023 · TOG/SIGGRAPH。来源：[论文](https://arxiv.org/html/2308.04079)。

- 问题：梯度驱动增长与实时渲染如何结合？
- 方法：各向异性协方差、clone/split、tile光栅化。
- 证据：§5、Fig8增密消融、§7.4；标准三组场景。
- 局限：作者：观测不足、细长斑块、popping等伪影。
- 选题启示（本次判断）：未形成分裂前实测帧时预算控制。

### P02 Revising Densification

状态：2024 · ECCV。来源：[论文](https://arxiv.org/html/2404.06109)。

- 问题：梯度信号与重建误差、点数增长不一致。
- 方法：像素误差引导，增长限额，修正克隆不透明度。
- 证据：§3.3–3.4、Table1、Fig4、§4.5；Mip五次均值PSNR27.45→27.61。
- 局限：作者：部分场景仍欠拟合；视角外观和投影等因素待解决。
- 选题启示（本次判断）：Fig4为相同点数比较，不能替代相同帧时。

### P03 Taming 3DGS

状态：2024 · SIGGRAPH Asia。来源：[论文](https://arxiv.org/html/2406.15643)。

- 问题：有限资源下如何保持质量、加快训练？
- 方法：最终高斯数预算B、增长计划、多视角贡献及底层加速。
- 证据：§3.2 Eq2、Tables1–2、§6；RTX A4500，标准三组数据。
- 局限：作者：更好探索、占据和盲区恢复仍有空间。
- 选题启示（本次判断）：B是最终数量；提及延迟应用不等于实现帧时预算控制。

### P04 Mini-Splatting

状态：2024 · ECCV。来源：[论文](https://arxiv.org/html/2403.14166)。

- 问题：空间聚集和覆盖不足浪费高斯。
- 方法：blur split、深度重初始化、交集保持/重要性简化。
- 证据：Figs3–4、Tables1–3、AppendixG；Mip约3.35M→0.49M。
- 局限：作者：天空深度不确定；采样比例和质量所需点数仍难选择。
- 选题启示（本次判断）：分裂依据为最大混合贡献像素面积，不能误写成完整投影面积。

### P05 SteepGS

状态：2025 · CVPR。来源：[论文](https://arxiv.org/html/2505.05587)。

- 问题：如何有理论依据地决定分裂和方向？
- 方法：分裂矩阵负特征值、对称子高斯、最陡分裂方向。
- 证据：方法、Table1、AppendixA.2 Eq8；V100，Mip仅7场景。
- 局限：所读部分未见独立局限节；局部下降理论不等于全局最优（本次判断）。
- 选题启示（本次判断）：已有增量点数预算和least-K选择；单纯预算选分裂不是新意。

### P06 Improving Densification

状态：2025预印本 / CVPR Findings 2026。来源：[论文](https://arxiv.org/html/2508.12313)。

- 问题：增密对象、分裂几何、恢复训练如何改善？
- 方法：边缘评分、长轴分裂、恢复剪枝、多步更新、增长控制。
- 证据：Table6同点数；A.8 Fig15分裂距离改变FPS和LPIPS；PDF13–14页已视觉核对。
- 局限：作者A.4：几何面积最优尚未综合颜色、不透明度与其他重叠高斯。
- 选题启示（本次判断）：已证明重叠与速度权衡；不能将发现该权衡本身作为创新。

### P07 Speedy-Splat

状态：2025 · CVPR。来源：[论文](https://arxiv.org/html/2412.00578)。

- 问题：无效像素和冗余图元拖慢渲染。
- 方法：SnugBox、AccuTile精确相交、敏感度剪枝。
- 证据：§3–6、Fig2、Tables1–3；A5000，前向CUDA事件计时。
- 局限：作者：剪枝存在轻微质量损失，评分仍有改进空间。
- 选题启示（本次判断）：tile成本意识已有先例；其定位/剪枝不同于拟议分裂的净成本准入。

### P08 FlashGS

状态：2025 · CVPR。来源：[论文](https://arxiv.org/html/2408.07967)。

- 问题：大场景高分辨率下光栅化浪费严重。
- 方法：精确椭圆tile相交、任务调度、流水线混合。
- 证据：v2方法§3–7和Figs7–9；另核对正式CVPR摘要。
- 局限：旧v2未见单列局限；实际耗时仍受调度和内存影响（本次判断）。
- 选题启示（本次判断）：主要改变渲染器；不同版本速度数值不混用。

### P09 StopThePop

状态：2024 · TOG/SIGGRAPH。来源：[论文](https://arxiv.org/html/2402.00525)。

- 问题：近似深度排序造成视角不稳定。
- 方法：分层重排、精确裁剪、负载均衡；可配不透明度衰减。
- 证据：§3–5、Fig6、Tables5–7、AppE；同种群总帧时4.797→4.986ms。
- 局限：作者：复杂几何仍无完全正确排序，未建模重叠体积。
- 选题启示（本次判断）：排序变快不必然总帧时变快；不能只优化单一计数器。

### P10 Faster-GS

状态：2026 · CVPR。来源：[论文](https://fhahlbohm.github.io/faster-gaussian-splatting/)。

- 问题：如何分清训练加速来自实现还是表示改变？
- 方法：布局、反向并行、优化器融合、裁剪排序等系统优化。
- 证据：§3–6、Fig1、Tables1–4；主要RTX4090，另测3090/5090。
- 局限：作者：优化器仍有瓶颈；精度、融合存在取舍。
- 选题启示（本次判断）：需要同渲染器和计时边界，避免把实现差异算成增密贡献。

## 从重复问题、结论差异和共有边界提炼问题

**重复问题：有限容量应花在哪里。** Revising、Taming、Mini、Steep、SAD、LeGS都在分配表示能力；换一个评分函数本身很难说明独立贡献。应明确评分究竟解决了哪个可观测失败。

**结论差异：更细的建模未必更好。** SAD的逐轴投影指标消融没有自然胜过标量方案，涉及旋转优化的解释仍为作者假说；StopThePop同种群计时表明某阶段变快可能被另一阶段抵消。不能把更精确几何或更少tile直接等同于更快整帧。

**共有评价边界：数量并非实际设备时间。** 数量预算、内存容量、LOD比例、训练时长、GPU前向帧时是不同约束。此处是横向分析，不是说所有论文都承认这一点，也不是声称前人从未测FPS。真正要测的是：在同一个渲染器中，两个点数接近的表示是否持续存在可利用的成本差异。

**相近作者明确留下的空间：相互作用。** SAD指出独立高斯评价忽略支持重叠；Improving已经观察到子项距离改变重叠和渲染队列。可以进一步研究“是否在执行分裂之前准确利用这种差异”，不能再将“重叠影响速度”的发现据为己有。

**统计与系统成本必须区分。** Counting Contributions说明遮挡会污染增密统计；ByteSplat说明tile硬件容量可用于剪枝。前者改善质量信号，后者控制既有负载。拟议方案的贡献必须在分裂准入和实测净开销之间建立有效联系。

## 对上一轮首选Q2的补查

[Learn2Splat](https://arxiv.org/html/2605.15760v2)（本轮看摘要、§4、§5及附录索引）已明确研究跨参数/跨高斯相关更新，并以相同墙钟时间评价优化器。所读部分没有直接确认“出生兄弟的共同/相对坐标Adam”已被实现；但这不构成其未被其他优化文献研究的证明。

[Decomposing Densification](https://arxiv.org/html/2507.20239v1)（摘要、方法、消融、结论）分析split/clone各自承担的扩散与局部细化，使用分阶段策略和多分辨率；它讨论的是增密操作与时序，不能仅凭标题将其当作共同/相对坐标优化的先例。

BOGausS已经做生命周期与状态继承；SteepGS已经使用对称子位置。这两者都必须区分。Q2待验证的发现应是：“分裂事件产生可重复的共同/相对曲率或梯度统计差异，且普通学习率调参无法消除损失。”仅写x1=c+d、x2=c-d以及Adam不具有旋转不变性，学术贡献仍不足。

## 推荐选题的具体可检验版本

研究问题：给定同一个渲染器、分辨率和目标视角分布，是否能够在增密前预测一次分裂的净渲染开销，并在相同实测帧时下获得比点数预算更高的重建质量？

第一版固定：现有质量评分、子高斯生成方式、优化器、训练视角顺序和渲染器。先不学习策略，也不设计新形状。

定义ΔW_i(v)=W(拟议子项集合,v)-W(父项,v)。W可以从精确或近似Gaussian-tile交数起步，但只作为代理；需要用GPU毫秒数校准。低透明度、遮挡早停、排序、线程分歧和显存访问都会使简单相加失效。局部成本允许为负，但不预设负成本事件真实存在或足够多。

预算是整批候选执行后预测帧时加安全余量不超过目标，且训练峰值显存不越限；运行中定期实测修正。负ΔW不等于免费：新增参数、Adam状态和临时缓存仍增加显存。若单项变化小于测量噪声，先做批量受控分裂并报告可辨识范围，避免给每个父项虚构精确毫秒标签。

理论目标不写“任意视角硬实时保证”；先只对预先定义的视角集合/分布报告平均帧时、p95、超预算比例。成本校准只用训练视角或独立校准路径，最终留出测试路径不参与选项和调参。

## 最小验证与继续/停止标准

### 阶段A：先检验问题是否真的存在

使用已有truck模型或训练完整检查点；模型PLY只能做渲染/成本诊断，续训必须包含优化器、迭代数及必要随机状态。固定设备、渲染器、分辨率和相机路径；预热、CUDA事件计时并同步，重复测量，记录噪声。

比较N、投影半径/面积、tile相交数、有效贡献/混合队列统计对实际前向帧时的解释力。不同视角的相关性只是初步线索，还需相同父集合、相同分裂数、不同候选方案的干预对照。采集受控批次的实际Δms，检查方向、排序及跨视角泛化。

继续：净成本代理在留出干预批次上优于数量/半径等简单基线，差异超过重复计时误差，而且存在质量价值相近、成本明显不同的候选。

停止或换代理：只能解释总模型大小却不能解释分裂增量；候选差异落在噪声内；或廉价半径约束已获得同样收益。统计相关不等于能分配预算。

### 阶段B：只做必要的短续训

从同一完整检查点顺序运行：原版；数量预算；半径或面积约束；净成本准入。保持相同候选质量信号。另加只按子项成本、不减父项的消融，以判断“净增”是否真有价值。对照至少包含Taming式数量分配，不能只比弱原版。

报告两种曲线：相近数量下的质量-毫秒；相近实测毫秒下的质量。记录PSNR/SSIM/LPIPS、平均/p95前向帧时、数量、训练峰值显存、总训练时间及估计器开销。暂不声称整应用端到端时延。

继续：超过重复/随机误差的质量-时延Pareto改善，估计器开销可接受，且收益不能完全由更少点数、裁剪差异或弱基线解释。失败：只有点数减少、实测时间没有改善；仅一个视角有效；或代价估计抵消训练收益。验证不依赖“无额外开销”承诺，应直接报告取舍。

### 本机安排

第1–2个工作日先完成计时与受控干预；第3–5日视诊断结果实现准入和短续训。这是工期估计，不是已做完的实验。先校准单次运行耗时，再把第一轮GPU试验控制在约2小时内；本轮新增GPU实验为0。大模型顺序运行，不同时在12GB设备保留多份模型。若需改光栅CUDA内核才可取得关键统计，应重新估工期，不承诺新手两天完成。

truck通过只是存在性测试。后续至少补不同几何、遮挡和分辨率的场景，多随机种子，并比较简单面积/数量预算和强增密方法；没有这些不能写泛化结论。
