# 当前裁剪前向下，端点L1直接替换是恒等操作

2026-10-23T01:58:33.412399+08:00。只读本地源码与代数检查，无GPU、无训练、无图像效果测量。

本地 `gaussian_renderer/__init__.py:119` 在返回给训练器前执行 `rendered_image.clamp(0,1)`；`train.py:119–126` 对其结果计算 L1 和 DSSIM。

对所有当前前向值 c∈[0,1]：目标为1时，|c−1|=1−c=max(0,1−c)；目标为0时，|c|=c=max(0,c)。所以仅将饱和端点的 L1 改成所提单边 hinge、保持其余项不变，其损失值完全相同；在开区间导数相同，端点亚梯度实现可能不同，不能据此凭空声称可重复的实际收益。源clamp在范围外的链路也不会因该L1替换而重新产生梯度。

**判断范围：**不建议为这个直接替换实现先跑端点统计或训练。候选#22全部成像问题与可能的其他损失仍未知；使用未裁剪原生输出、改变DSSIM处理或新增删失似然是需要另行明确的干预，不能把它们偷换成已经检验过的同一方案。这不是查新ABANDON，也不是证明Truck不存在传感器饱和。

有限数值表仅检查源码推导的例子，不是代替真实数据效应的toy实验；主要证据是覆盖整个[0,1]定义域的恒等式。
