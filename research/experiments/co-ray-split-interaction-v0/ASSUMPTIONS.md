# Preparation assumptions, recorded before implementation

2026-10-23. Status: PREPARATION_ONLY; no execution authorization is inferred.

1. Only route #44 is in scope. This is a finite-event renderer diagnostic, not training or a test of a grouping method. Smaller immediate damage does not imply better recovery or training.
2. The only model source is `split-diagnostic-v0/early3600_seed0/event_state.pth`: 770456920 bytes, PREBIRTH global iteration 3600, 1058297 rows. Its trusted local pickle is loaded on CPU with `weights_only=False`. Six raw fields are retained; optimizer and other capture members are discarded before copying the six fields to CUDA. No `restore`, `training_setup`, `Scene` construction, optimizer instance, backward, or update is permitted.
3. The fixed 1481 historical LAS parent IDs come from `matched-count-v0/early/las_split/selection.json`. `split_children.pt` witnesses only parent IDs, child XYZ, and activated scaling. All six child fields are regenerated once on CUDA using the original LAS source operation order, plus block then minus block. Exact XYZ and activated scaling equality are mandatory. Historical raw child scaling was not saved; its raw exactness must not be claimed by taking a logarithm of that witness.
4. Every arm has the same original N plus all 2K child slots. A split parent and each inactive child use raw opacity -100, which must activate to exactly zero in the current CUDA dtype. Other fields and ordering stay fixed. Exact unclamped RGB equality is required for unpadded original versus empty padded slots, filtered canonical full birth versus full padded slots, and forward versus reverse subset application. Failure is INCONCLUSIVE with no tolerance fallback.
5. Exact 219 training camera records are restored from the PUP run-v2 `CAMERAS.json` using stored dtype, shape, values, scalar fields, and array hashes. Loaded dimensions are 979 x 546, resolution 1. The historical 251-record metadata dimensions 1957 x 1091 are not used to scale matrices. Source JPEGs must already have the exact loaded RGB dimensions; no resizing is allowed.
6. Native commit is `54c035f7834b564019656c3e3fcc3646292f727d`; use the existing `/home/administrator/venvs/3dgs/bin/python` in WSL Ubuntu-22.04. No build or install is allowed. Present source/binary pins establish the current native protocol, not an exact historical training trajectory.
7. Root will supply a frozen contract and arms manifest, their SHA256 values, exact training views/subsets (global prebirth parent IDs), renderer interactions, loss definition, scientific gates, and a recorded code review before launch. The supplied templates deliberately cannot launch. The executor never selects scientific parents/views or interprets gates.
8. Raw renderer RGB is the native rasterizer output before the Python final RGB clamp. Native SH lower clamp, alpha threshold/cap, early termination, sorting, and CUDA arithmetic remain part of that renderer. A finite K does not by itself isolate alpha as its sole cause. Final-clamp effects are kept separate.
9. CPU float64 K = R_AB - R_A - R_B + R_0 is renderer interaction. GT loss interaction is a different quantity; even additive rendering can have nonzero squared-loss interaction. The CPU helper reports both and the additive-render loss counterfactual without drawing an efficacy conclusion.
10. Launch is one attempt into a new `run-*` directory inside this directory. The contract bounds raw files to 4 GiB, aggregate sampled host RSS to 8 GiB, Torch CUDA allocated/reserved peaks to 4 GiB, and the external main wall to 300 seconds. The allocator bound is not a full-process device-memory bound. Best-effort nvidia-smi process telemetry is recorded when WSL reports it; unavailable PID/memory telemetry is explicitly marked unmeasured and is not a launch gate. There are no automatic retries. Worker/supervisor failures retain partial artifacts and are INCONCLUSIVE.
11. A separately frozen `projection` phase runs only the original PREBIRTH model, once per specified calibration view. Frozen parameters remain without gradients; a screen-space graph is permitted only to retain the native saved geometry buffer. No backward is called. The 11-saved-tensor ABI and pinned 128-byte geometry prefix layout are mandatory. Only public radii and initialized selected means2D/conic entries are read; inactive entries are zero-filled, and `internal_radii` is never read. This phase never regenerates births or renders effects. Its output is input to root's separately reviewed graph helper.
12. Independent numeric audit requires saved LAS proposals, not only worker-declared hashes. Effects therefore save selected raw parent fields, all six regenerated raw child fields, prelog activated child scaling and activated child opacity in one immutable NPZ. Six representation-gate RGB arrays per effects view are also saved. These exports are included in the prelaunch 4 GiB bound; they do not introduce forwards or new scientific selections.
