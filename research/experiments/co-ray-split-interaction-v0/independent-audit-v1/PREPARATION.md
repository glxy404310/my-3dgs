No experimental arrays, Torch, models, simulations, or GPU computation were run
during preparation. Only lexical Python compilation, JSON parsing, help, and
source hashes are permitted for preparation verification. This directory writes
nowhere outside itself. Actual invocations require a separately root-frozen
contract containing the completed producer/graph/host-record path and SHA256 of
every manifest, not the placeholders in AUDIT_CONTRACT.template.json.

Root must read all four CODE files and freeze their complete hashes before any
actual audit. `run-audit.py --help` and `audit.py --help` are stdlib-only. Actual
execution uses the existing Linux environment, no installation or compilation:

```
python -B run-audit.py --run --contract /absolute/ROOT_AUDIT_CONTRACT.json --contract-sha256 ACTUAL64HEXSHA --output /absolute/independent-audit-v1/run-ROOTCHOSEN
```

The stdlib supervisor hides CUDA with CUDA_VISIBLE_DEVICES='', fixes BLAS and
Torch CPU threads to one, samples aggregate process-tree RSS, and terminates the
single attempt at 120 external seconds or 8 GiB sampled RSS. It saves its own
AUDIT_HOST_RECORD.json. A child audit PASS is ineligible unless that supervisor
completes successfully and its external time plus the three root-observed phase
times is at most 600 seconds. Sampling does not certify unsampled RSS spikes.
The actual worker imports NumPy/SciPy/PIL and CPU Torch only after actual pins and
root freeze checks. Trusted event/witness CPU deserialization reads existing
optimizer payload as bytes/data; it constructs no optimizer or model. It never
imports producer, graph helper, repository, rasterizer, or CUDA modules, and never
calls rendering, backward, gradient evaluation, optimization, or training.
