# Independent PUP quality audit v1

Frozen before reading any new real image array. This is an independent CPU-only verification of the saved native PUP evaluation, not a new quality acceptance threshold. The old formal SSIM audit stays FAIL_UNCHANGED even if this audit passes.

Only stdlib, NumPy, SciPy and PIL are allowed. Do not import the producer, its metric helpers, torch, Scene or a renderer. No native rerender, backward, optimizer, scoring, pruning or training occurs. Preparation may inspect source/JSON structure/file names and tiny synthetic arrays only. Root reviews/freezes this contract, audit.py and run-audit.sh before the one permitted launch.

Launch requires root-supplied actual paths and SHA-256 values for the new evaluation-v1/run-v2 RESULTS.json, SUPERVISOR.json, RAW_MANIFEST.json, evaluation-v1/EXTERNAL_RUN_V2.json, and preserved failed-v1 evaluation-v1/EXTERNAL_RUN.json. Every path must be the canonical expected path. Missing values, placeholders and overrides are rejected. The v2 external record must prove exit_code=0, attempts=1, hard_limit_seconds=188, within_188_seconds=true, within_all_primary_200_seconds=true and actual_host_wall_seconds in (0,188]. Both primary external command durations, including the failed v1, must sum to <=200 seconds. The failed v1 was a namespace-path provenance error before any forward, and must remain preserved; v2 is an explicit separate root-directed tool repair. The original evaluation files are read-only. Only this audit's run-v1 is created, and it must not exist before launch. No automatic retry exists.

The audit independently loads all 165 raw CHW float32 arrays: 33 GT, teacher, all219 and NanoGS from the pinned prior manifest, plus 33 PUP from the new manifest. It verifies exact memberships, SHA-256, bytes, shape [3,546,979], finiteness and [0,1] range, new array hashes/PNG pixels, and GT correspondence to pinned source photographs. It independently recomputes the 132 four-arm metric rows, the 32-test means, each arm's own worst four by GT MSE (ties by view), the signed summary and per-view differences, and the four largest test PUP-minus-all219 GT-MSE increments (exploratory). It verifies exact source-pixel bodies in fixed 000016/000017/000105 full and top220 five-column panels and exploratory top-four full panels, with the producer's separate 28-pixel label band. The crop is always x0,y0,w979,h220. No image enhancement is permitted.

Predeclared technical absolute tolerances, with separate dimensions: MSE 1e-12; PSNR 1e-9 dB; SSIM 1e-10; float64 maximum absolute RGB difference metric 1e-12. Raw/PNG/panel pixels are exact. Zero MSE must have null PSNR and a true explicit infinity flag. SSIM is independently implemented in float64: normalized 11-tap Gaussian sigma1.5, separable scipy.ndimage.convolve1d axes1/2, constant-zero padding, population variance/covariance, C1=.01^2, C2=.03^2, all-CHW mean. No prior GPU SSIM table is used.

All CONFIG protected files, old raw entries, new control/raw/PNG/panel files, score proof and model inputs are SHA-256 checked before and after. The 219 train camera records are compared with score canonical records; all 33 evaluation records and test membership are compared with the pinned old records; all canonical source-photo hashes are checked. PUP count/PLY bytes/SHA and six independently reconstructed raw-field hashes are compared with scoring proof. Recorded model before/after equality, SH3, exact 33 forwards, zero backward/optimizer, supervisor success, GPU allocation and RSS limits are checked as declarations. Saved pixels and declarations cannot independently prove the native execution history; that limitation is explicit in the report.

The actual external main plus audit command wall must total <=300 seconds. Audit external limit is100 seconds; internal supervisor stops at94 seconds; launcher timeout sends TERM at98 seconds and KILL one second later. Aggregate sampled process-tree RSS limit8GiB. The command is CPU-only and one-shot, with partial rows, errors and logs retained. A timeout/memory stop/missing record is inconclusive. Passing means saved-artifact consistency only, never a scientific quality or novelty claim.
