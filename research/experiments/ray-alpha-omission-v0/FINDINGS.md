# 原生候选列表内的 alpha 累计遗漏

2026-10-23。结论：**累计遗漏现象明显，但恢复这些项使当前冻结模型对 GT 更差，按原门槛停止当前部署路线。** 原判定 `STOP_CURRENT_CUMULATIVE_OMISSION_DRIVEN_DEPLOYMENT`；工具有效，四门槛依次为 `[true,true,false,false]`。

## 固定诊断与结果

Truck 30k 教师，219训练相机按文件序取固定秩 `[0,31,62,93,124,155,186,218]`，对应000002、000037、000072、000108、000143、000179、000214、000251。每图16×16均匀整数像素中心，共 **2048** 个样本；GT 不选择相机或像素。原生979×546、SH3、黑背景、无AA/曝光。

只读取得原生 tile 列表、投影 conic/opacity/RGB及顺序，保存八个 [CACHE_*.npz](run/TRACES.json)。A 按原生 FP32 规则重放，含 alpha<1/255 跳过和 T<1e-4 早停；触发早停的当前项不累加。B/C 从同一 FP32 缓存升为 FP64，均关闭 T 早停；B 保留原 alpha 阈值，C 保留全部正 alpha。两者使用同一顺序、.99 cap、power>0 排除及最终 clamp，只隔离当前候选支持域内的 alpha 跳过。

A 对原生最终 RGB 的最大通道差 **7.152557e-7**，通过≤2e-5的原工具门槛；n_contrib 2048项全一致，最大 T 差1.05612e-6。二进制 hash 只识别已加载文件，不能证明其由当前源文件编译；该 parity 提供本轮行为对照。

| 预定门槛 | 实测 | 判定 |
|---|---|---|
| ≥1%样本 B/C 最终通道差>1/255 | **1100/2048，53.710938%** | 通过 |
| ≥2视角各≥1%样本超标 | 全部8视角满足 | 通过 |
| ≥一半超标像素的所有正alpha项RGB≤1 | **0/1100** | 未通过 |
| C 对固定GT整体MSE≤B | C更差 **3.139008%** | 未通过 |

B 整体 GT MSE为0.0018455214327494241；C为0.0019034525069448827。B/C 最大通道差0.05147271155。因而不能说累计影响微小，也不能把“求和更完整”当作照片质量改善。

普通 RGB 条件要求列表中**每一个**正 alpha 项都不超过1，极小正 alpha 的项也计入。0个符合样本**不证明极端 SH 导致了差异**；这不是因果隔离。GT 门槛独立失败，已足以按预定规则停止，不能事后放松普通 RGB 条件救结果。

## 独立复核、成本与结论边界

[独立 CPU 分析](run/INDEPENDENT_ANALYSIS.json)重算全部2048行的 RGB 衍生指标、八视角汇总与四门槛，并比对全部缓存中的 native/GT RGB、T、n_contrib。八个 NPZ 均在；每图再按固定样本秩16、48、80、112、144、176、208、240，独立标量重放 B/C，未导入原合成函数。**64条射线**的最终 RGB 最大差1.110223e-16、总 alpha 差0；并非独立重放全部2048条。

仅八次原生 forward，零 backward、零训练、无 optimizer、零参数更新；六组教师参数前后 hash 一致。阶段墙钟16.0582秒，峰值 allocated 1,420,137,472字节；独立 CPU 复核2.0162秒。均在原300秒/10GiB及CPU30秒预算内。
