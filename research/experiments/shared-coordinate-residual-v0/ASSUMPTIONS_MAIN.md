# Main implementation assumptions

This is preparation for the locked `CONTRACT.md`, not an execution result. Only the main script, launcher, and this file are changed. No model, real matching, native render, GPU operation, or scientific run directory is created during implementation. The root must review the concrete implementation before its sole authorized launch.

- Locked contract SHA-256: `7536a2641dd54ef84c02b2159ee6ec31fa8fab895e4ef9001c367b33f9a2273c`. The implementation includes the pre-effect amendment requiring native domain/linearity validation of every training nuisance q used to estimate a shared field, as well as all heldout q. No validation render is replaced by an image warp.
- The structure tensor is the **mean** of the 169 grayscale-gradient outer products. Its eigenvalues therefore use intensity-gradient squared units per sample. The GT-only texture gate is unchanged across checkpoints. Known-shift witnesses apply the same texture rule to the teacher source rather than pretending its synthetic target is clean GT.
- `sigma_zero` is the RMS of feature-difference L2 norms pooled over all finite base/repeat and base/zero-copy features on all three witness images. RGB max/MSE gates apply separately to every repeat and zero-copy image. `sigma_shift` is the maximum of the three known-shift vector-error RMS values.
- Native validation uses R_q as reference and R_0 as target: R_q(p) matches R_0(p+d_native). This is the same sign as Hq because native helper H satisfies phi_q(p) ~= phi_0(p+Hq). Scientific GT matching remains GT(p) versus R_0(p+d).
- B_h=(F_plus-F_minus)/2 and B_half=F_half_plus-F_half_minus are assembled directly from normalized feature samples. They are per main-step q responses, not derivatives per radian or world unit. A uses the fixed .125px spatial difference.
- All main linear solves first divide each nonzero column by its L2 norm, use `np.linalg.lstsq(rcond=1e-10)` on the complete design, and unscale the coefficients. A zero column uses safe divisor 1 and remains zero. Raw and scaled singular values/ranks/scales are archived. The separate feasibility rank uses relative 1e-8. The helper's nine-point quadratic solve uses the fixed full-rank six-column design; scaling changes neither its full-rank ordinary-LS solution nor its fixed rank-six requirement. No column is dropped and no ridge is used, including structurally redundant controls.
- Per-image affine uses `(1, normalized_y, normalized_x)` independently for dy and dx. This spans exactly the six-parameter affine displacement space; coefficient units/scales are archived. Shared translation is ordered `(dy, dx)`.
- Image-heldout folds use selected-list parity. Main fit-cell order is `(heldout_image_fold, spatial_eval_fold) = (0,0),(0,1),(1,0),(1,1)`. Each training and heldout nuisance uses only the opposite spatial fold. Stress has two image-heldout cells; all fit points are center and all evaluation points are edge. The original common mask never changes after capacity checks.
- The pose domain is checked on q's physical rotation/scene-normalized translation norms and the combined prediction at **every original common-mask point**, not only the fitting/evaluation subset. Native validation runs on every point of that same original per-image common mask and never changes it. Invalid finite-H points outside this mask do not create an additional gate. The main contract supplies only patch-center H; no claim of a continuous pixel-domain pose bound is made.
- Matching, Brown fields, and rho all use array-index coordinates. Native ndc2Pix places the optical center at `cx=(W-1)/2=489`, `cy=(H-1)/2=272.5`. Metadata records both these array-index principal coordinates and the scaled COLMAP boundary coordinates `(489.5,273)`. Focal lengths use the actually loaded native FoV and image dimensions.
- Capacity early stops use only necessary upper bounds. The final common mask is a subset of GT texture, GT texture plus real matching, and each completed single-checkpoint valid mask. If one such superset already fails the unchanged 48/16/6 requirements, `CAPACITY_UPPER_BOUND_FAILURE.json` records the proof and the actual two-checkpoint common mask remains explicitly unknown. Remaining forwards/controls are unexecuted and no method verdict is produced.
- Field RMS means `sqrt(mean(dy**2 + dx**2))`, in pixels. Concatenated four-cell field vectors are never averaged first. Means of displacement and RGB errors are equal-weight means of the twelve per-image means, after combining each image's two main spatial folds by point count.
- Matching is batched only for memory use. Every original point is attempted, every 289-candidate cost/NCC and refinement diagnostic is saved. Candidate feature cubes are omitted because the saved RGB inputs reconstruct them. NaN/Inf and explicit validity masks are retained in NPZ; JSON maps nonfinite values to null, without changing scientific masks or gates.
- GT/base RGB is saved losslessly as float32 NPY at original native resolution. Every FD image saves all 120 native 15x15 RGB patches, features, and the assembled A/B/H diagnostics. Every fitted native render saves all 120 RGB patches with fixed support halo 12 (25x25), its complete validation grids, and actual sampled 13x13 RGB predictions for evaluation. For exact independent bilinear replay, evaluation artifacts also save the four source corner RGB values and positions for every predicted pixel, including any sampling position beyond the validation patch's halo.
- All twelve displacement overlays are saved for each checkpoint. Explanatory panels show a fixed six lowest and six highest refined matching costs across the common mask, ordered by `(cost, selected_view_index, original_grid_index)`, with no manual deletion. The overlay's displacement arrows use a declared factor of 8 for legibility; saved numeric displacements retain their true pixel units.
- Original cameras are never used as mutation targets; only new pose copies are passed for perturbations. Finally checks compare original R/T, normalization metadata, dimensions/FoV, all four native matrix/center fields, original GT, and alpha mask against pre-operation snapshots. No restoration is required because the script performs no original-camera assignment. A failed comparison is preserved as an integrity failure, not silently repaired. Original Gaussian parameter/source PLY hashes are checked in the same finally path.
- Expected native Python sources and both helpers are checked before native model loading. The current compiled rasterizer and simple-knn files, camera metadata, source point cache, selected JPEGs, both checkpoint PLYs, contract, helpers, main script, and launcher are recorded and rehashed. Python module import can create normal bytecode caches; it never writes scientific images or model files.
- The external `timeout` watchdog starts before the scientific Python process and sends TERM after 295 seconds, then KILL at 300 if needed. The final five seconds are reserved only for failure preservation/cleanup; scientific work does not continue after TERM. The Python process also checks a 300-second internal timer that begins before heavy imports. Budget/signal failures retain the original reason and partial artifacts, prohibit restarts, and mark unfinished integrity checks unknown. The outer launcher records its measured process/pipe wall time separately; an in-process timestamp sampled before JSON serialization is labeled with that narrower scope. The launcher must confirm exit zero, successful log pipe, and wall time at most 300 before any in-process result is considered externally complete.
- Each checkpoint retains only the exact twelve selected original camera references after archiving the original 219-name ordering. This releases unused training images without changing any selected image/matrix, fitting mask, model parameter, or control.
- Stress capacity/rank/pose failures are recorded as stress unknown and do not replace or rescue main OOF. A budget, signal, or integrity failure during stress still makes the whole required diagnostic incomplete. No new threshold is invented to certify center-to-edge extrapolation; stress metrics remain descriptive.

Runtime, memory, and the 300-second feasibility remain unknown. The required full protocol contains 600 core forwards, six zero/repeat witnesses, 192 heldout main pose renders, 144 training main pose renders, 96 heldout stress pose renders, and 72 training stress pose renders: **1110 forwards if every stage completes**. No reduction or automatic rerun is permitted to meet the budget. Render attempts and successfully completed forwards are counted separately so a signal in an in-flight native call is not silently called a completed forward.
