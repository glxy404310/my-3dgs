`collect.py` is a reviewable, unexecuted implementation. Preparation used source reads, AST parsing/compilation and non-ML tests (NumPy scalar serialization and fake-object native-function control flow). No Torch/native module import, model load, CUDA operation, actual forward, backward, optimizer call, runtime resource collection or scientific experiment occurred. Runtime correctness, actual memory/time limits, observer invariance, package compatibility and endpoint usability remain unverified. Root owns the contract, authorization, complete review, supervision, tree reaping and independent acceptance audit.

It neither loads the package nor creates output.

Its initial stack anchor gains `first_iter = collector.restore(locals())`; the hook returns3500 before native increment/range construction. This omits the old wrapper's redundant ordinary-checkpoint restore before its full-package overwrite and explicitly records that operational difference. Unexpected camera order fails instead of replacing sampled cameras. The previous historical fused-SSIM uncertainty is not resolved or inferred by this new worker.

Native GUI/TensorBoard/reporting are disabled and evaluation/save/checkpoint lists are empty, with operational differences recorded. Native render and backward calls are counted without changing arguments or return values; the restored scene and exposure optimizer instances count their completed calls. All birth/prune/reset methods fail if reached. For each of100 views the worker saves unmodified screen gradient Nx3 float32 and radii N int32 as lossless atomic NPY files, with shape/dtype/bytes/hash and camera/loss metadata. An independent CPU auditor can reconstruct each native per-visible 2D norm addition and denominator from these arrays. It hashes the actual GT tensor, mask, camera transforms and source JPEG. This intentionally records no replacement GT or synthetic positive example. Per-step observation compares live tensor identity/pointer/version and RNG content before/after; copy/disk time is charged and recorded. It does not claim full byte equality at every intermediate step.

The endpoint preserves complete model capture and six raw fields, all raw live leaf gradients and None values, full scene/exposure optimizer states and mappings, exposure and its gradient, ADC numerator/denominator/max-radii, activeSH/config metadata, screen gradient/radii/visibility, background/loss, all RNG, full camera history and remaining stack/index order. RNG is not restored to conceal observer changes.

The runtime provenance records actual fused/ordinary SSIM callable source and loaded fused/raster module files, loaded raster binary against its preimport pin, Torch/CUDA/GPU/runtime identities and source diff. Driver proc identity may be unavailable under WSL and is explicitly null then; root host evidence must supply additional provenance if needed. Full process GPU memory is not measured by worker allocator counters.

Success status is only `CAPTURED_PENDING_ROOT_AND_INDEPENDENT_AUDIT`. It does not establish scientific materiality, a problem worth solving, a novel method, method efficacy, or independent GPU execution certification. Failures in an output directory created by this worker write INVALID; no retry, recovery or continued training is implemented. An existing output directory is never overwritten by the failure handler.
